# Midnight Field Guide — Beast Mastery Hunter

A colorful, mobile-friendly, **PvE-only** World of Warcraft: Midnight Season 2 gearing guide for a returning **level 90 Beast Mastery Hunter**.

## Features

- Responsive static HTML/CSS/JavaScript website with no build dependencies.
- Level 90 roadmap, three PvE gearing paths, upgrade ladder, class priorities, and gear targets.
- Weekly checklist stored locally in the browser.
- Playstyle selector and talent-import copy buttons.
- Returning-player changes primer and linked sources.

## Deploy to Vercel

1. Go to https://vercel.com/new and sign in using GitHub.
2. Import **jpetree331/midnight-wow-how-to-gear**.
3. Use Framework Preset **Other**, with no build command and output directory set to **.** (repository root).
4. Click Deploy. Further commits to main should trigger redeployments.

No environment variables, API keys, package installs, or framework build steps are needed. To preview locally, run python -m http.server 8000 and open http://localhost:8000.

## Freshness & scope

Information snapshot: **October 31, 2026, World of Warcraft patch 12.1.5 / Midnight Season 2**. This site is NOT an automatically updating database. See the website's Sources & notes for patch notes and guides; re-check after later patches or seasons. PvE only: no PvP recommendations.

Checklist completion and selected playstyle stay in your browser's local storage and aren't uploaded. This is an unofficial World of Warcraft fan resource and is not affiliated with Blizzard Entertainment.
